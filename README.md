# تلاوة — تطبيق القرآن الكريم بصوت القرّاء مع متابعة الآيات

تطبيق أندرويد (Kotlin + Jetpack Compose) بواجهة عربية كاملة من اليمين لليسار، يعرض المصحف كاملاً بالرسم العثماني
ويُبرز الآية التي يتلوها القارئ لحظة بلحظة مع تمرير تلقائي إليها.

## المزايا
- **المصحف كاملاً**: ١١٤ سورة بالرسم العثماني (نص مشروع تنزيل) بخط «أميري قرآن».
- **القرّاء**: الشيخ محمد صديق المنشاوي، والشيخ عبد الباسط عبد الصمد (مرتّل).
- **تزامن الصوت مع النص**: الآية الجاري تلاوتها تُظلَّل بالذهبي، والشاشة تنزل إليها تلقائياً.
- **اضغط على أي آية** ليبدأ القارئ منها، واضغط على البسملة لتبدأ السورة من أولها.
- **تكرار الآية** (للحفظ)، والانتقال للآية السابقة/التالية، والانتقال التلقائي للسورة التالية.
- **تشغيل في الخلفية** مع إشعار وأزرار تحكم على شاشة القفل والسماعات، وإيقاف تلقائي عند فصل السماعة.
- **تغيير القارئ أثناء التلاوة** يكمل من نفس الآية بالصوت الجديد.
- **دون إنترنت**: النص يُحفظ بعد أول فتح لكل سورة (أو دفعة واحدة من القائمة ⋮)، والتلاوات المسموعة تُخزَّن مؤقتاً حتى ١ جيجابايت.
- **متابعة من حيث توقفت**، وبحث بالاسم (دون تشكيل) أو بالرقم، وتكبير/تصغير الخط، ووضع ليلي تلقائي.

## كيف يعمل التزامن
تلاوات المصدر مسجّلة **آية بآية** (ملف صوتي لكل آية). عند تشغيل سورة تُبنى قائمة تشغيل في ExoPlayer:
`البسملة ← الآية ١ ← الآية ٢ ← …`، ومعرّف كل عنصر هو `رقم_السورة:رقم_الآية`.
عند انتقال المشغّل لعنصر جديد يصل حدث `onMediaItemTransition` فيعرف التطبيق الآية بدقة تامة ويبرزها،
دون الحاجة لجداول توقيت.

## البناء
**Android Studio**: افتح المجلد ثم Run. (JDK 17، compileSdk 35، minSdk 26 = أندرويد 8 فأحدث)

**سطر الأوامر**:
```bash
./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

**GitHub Actions**: الملف `.github/workflows/android.yml` يبني APK مع كل push ويرفعه كـ artifact.
لبناء نسخة إصدار موقّعة أضف الأسرار: `KEYSTORE_B64` (ملف jks بترميز base64)، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.

## هيكل المشروع
| الملف | الدور |
|---|---|
| `QuranData.kt` | أسماء السور وعدد آياتها، القرّاء، أدوات النص العربي (إزالة التشكيل، الأرقام العربية، فصل البسملة) |
| `QuranRepository.kt` | جلب النص وروابط التلاوات من `api.alquran.cloud` وحفظها محلياً + الإعدادات |
| `PlaybackService.kt` | خدمة Media3 للتشغيل في الخلفية مع تخزين مؤقت للصوت |
| `QuranViewModel.kt` | حالة التطبيق ومنطق التشغيل والتزامن |
| `Screens.kt` | الواجهات: فهرس السور، شاشة القراءة، شريط التحكم |

## إضافة قارئ جديد
أضف سطراً واحداً في `Reciters.all` داخل `QuranData.kt` بمعرّف إصدار صوتي **آية بآية**، مثل:
```kotlin
Reciter("husary", "محمود خليل الحصري", "ar.husary"),
Reciter("minshawi_mujawwad", "المنشاوي (مجوّد)", "ar.minshawimujawwad"),
```
القائمة الكاملة: https://api.alquran.cloud/v1/edition?format=audio
